# FireBoost

Free Fire-focused Android game launcher and gaming utility foundation.

## Current build

- Android 8+ (`minSdk 26`)
- Free Fire package detection and launching
- Dark/red FireBoost branding
- Device information
- Battery settings shortcut
- Key-mapper foundation
- Performance-tools foundation
- One-click GitHub Actions debug APK build

## Build the APK

Open **Actions → Build FireBoost APK → Run workflow**. When the workflow finishes, download the **FireBoost-APK** artifact.

The project is designed to build remotely, so Android Studio is not required on the Mac used to manage the repository.

## Safety

FireBoost is intended for legitimate launcher, diagnostics, performance guidance, and input-configuration features. It does not include cheats, anti-cheat bypasses, memory modification, game-file modification, or emulator-detection spoofing.
